# 📚 Automated Attendance System for Rural Schools

A digital attendance management system designed to simplify student attendance tracking in rural schools. The platform enables teachers to record attendance efficiently, generate reports, and manage student records while supporting offline functionality for areas with limited internet connectivity.

---

## 📖 Overview

Many rural schools continue to rely on paper-based attendance registers, which are time-consuming and prone to errors. This project provides a simple and reliable digital solution that helps teachers record attendance, maintain accurate records, and reduce administrative workload.

The application is designed with accessibility and ease of use in mind, making it suitable for schools operating in resource-constrained environments.

---

## ✨ Features

* 📝 Digital student attendance recording
* 📅 Daily attendance management
* 📊 Attendance reports and summaries
* 📱 Mobile-friendly interface
* 📂 Student record management
* 💾 Offline attendance support
* ⚡ Fast and easy-to-use dashboard

## 🚀 Getting Started

### Prerequisites

* Node.js (v18 or later)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/mr-sandeep-offl/Automated-Attendance-System-for-Rural-Schools.git
```

Navigate to the project directory:

```bash
cd Automated-Attendance-System-for-Rural-Schools
```

Install dependencies:

```bash
npm install
```

Configure environment variables:

Create a `.env.local` file and add your required API keys or configuration values.

Run the development server:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```
